# Live Track VIA Rail

A Home Assistant integration that puts live **VIA Rail Canada** train positions on your map.

> ### Status: in design. Not built yet.
> There is no releasable code in this repository. It is public so the design
> record and attribution are visible from the start.

Covers VIA Rail services including the Canadian, the Ocean, the Skeena, Hudson Bay and the Corridor. Sibling integrations cover [Amtrak](https://github.com/StrausbergAutomationWorks/LiveTrackAmtrak) and [Brightline](https://github.com/StrausbergAutomationWorks/LiveTrackBrightline) from the same upstream feed.

If you install more than one of the three, they share a single upstream request
rather than making one each.
